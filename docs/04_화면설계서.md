# 04. 화면 설계서 — FabWatch

> 버전 v1.0 / 2026-07-06

## 1. 공통 디자인 토큰

산업용 모니터링 시스템 무드: 다크 대시보드 + 상태 색 중심. (현장 CIM 모니터 감성)

```css
:root {
  /* 배경 */
  --bg-base: #0F1419;       /* 전체 배경 */
  --bg-card: #1A2129;       /* 카드 */
  --bg-hover: #232B35;
  --border: #2D3742;

  /* 텍스트 */
  --text-primary: #E6EBF0;
  --text-secondary: #8B98A5;

  /* 설비 상태 (현장 표준 색) */
  --status-run: #22C55E;     /* RUN 초록 */
  --status-idle: #94A3B8;    /* IDLE 회색 */
  --status-down: #EF4444;    /* DOWN 빨강 */
  --status-pm: #3B82F6;      /* PM 파랑 */

  /* 알람 심각도 */
  --alarm-warning: #F59E0B;
  --alarm-major: #F97316;
  --alarm-critical: #DC2626;

  --accent: #06B6D4;         /* 포인트 (버튼/링크) */
  --radius: 8px;
  --font: 'Pretendard', sans-serif;
  --font-mono: 'JetBrains Mono', monospace;  /* 센서 수치용 */
}
```

- 차트: Recharts. 센서 라인 `--accent`, 임계치 warn 점선 `--alarm-warning`, crit 점선 `--alarm-critical`.
- 수치는 모두 mono 폰트 (자릿수 흔들림 방지).
- 반응형: 데스크톱 우선, 1024px 이하에서 카드 2열→1열. 점검 입력 폼은 태블릿(현장 사용) 고려해 터치 타겟 44px 이상.

## 3. 핵심 화면 상세

### S-1 라인 현황 대시보드
```
┌───────────────────────────────────────────────┐
│ 헤더: 로고 | 라인선택 | 교대(D/N) 표시 | 사용자 │
├───────────────────────────────────────────────┤
│ KPI 스트립: 가동률 | 금일 알람 | PM지연 | DOWN 수 │
├──────────────┬──────────────┬─────────────────┤
│ [LAMI-01]    │ [LAMI-02]    │ [SCRB-01]  ...  │
│ ● RUN        │ ● RUN        │ ● DOWN          │
│ 45.2℃ 2.1mm/s│ ...          │ 알람 2 ⚠        │
│ −94.8kPa 12A │              │ PM지연 배지     │
├──────────────┴──────────────┴─────────────────┤
│ 실시간 알람 스트림 (최근 10건, SSE 추가)        │
└───────────────────────────────────────────────┘
```
- 설비 카드: 상태 좌측 보더 4px 색상. 클릭 → S-3. 센서값은 2초마다 갱신(SSE), 임계치 초과값은 해당 심각도 색으로 깜빡임 1회.
- 데모 컨트롤(우하단 플로팅, ENGINEER+): 시나리오 주입/해제 패널 — 시연 시 여기서 드리프트 주입.

### S-3 설비 상세
- 상단: 설비 정보 + 상태 변경 버튼(권한별) + "AI 리포트 생성" 버튼(미해결 알람 있을 때 활성).
- 탭1 센서: 4개 실시간 차트(2×2 그리드) + 기간 선택 이력 차트.
- 탭2 점검: 해당 설비 이력 테이블 + PM 스케줄 카드(다음 예정일, OVERDUE 시 빨강).
- 탭3 알람: 알람 테이블 (OPEN 상단 고정, ACK/RESOLVE 버튼 인라인).
- 탭4 리포트: 리포트 카드 목록 (DRAFT 노란 배지 / CONFIRMED 초록).

### S-5 점검 이력 등록
- 유형 토글(PM/BM)에 따라 폼 분기:
  - PM 선택 → 해당 설비 체크리스트 자동 로드, 항목별 OK/NG/NA 라디오 + 메모.
  - BM 선택 → 4M 분류 셀렉트(필수) + 연계 알람 드롭다운(해당 설비 OPEN/ACK 알람).
- 시작/종료 datetime → 소요시간 자동 표시. 교대조 자동 판정(수정 가능).
- 저장 성공 → 목록 이동 + 토스트. NG 포함 시 "엔지니어 확인 대상으로 표시됩니다" 안내.

### S-7 AI 리포트 상세
```
┌─────────────────────────────────────┐
│ 제목 | 상태배지(DRAFT/CONFIRMED)     │
│ [원본 초안 보기] [편집] [확정]        │
├─────────────────────────────────────┤
│ 마크다운 렌더링 영역                  │
│ (편집 모드: 좌 에디터 / 우 미리보기)  │
└─────────────────────────────────────┘
```
- 생성 중: 스켈레톤 + "리포트 생성 중 (최대 1분)" 진행 표시. 실패 시 사유 + [재시도] [수동 작성].

## 4. 공통 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| StatusBadge | 설비 상태 4색 배지 |
| SeverityBadge | 알람 심각도 3색 배지 |
| SensorLiveChart | SSE 구독 슬라이딩 차트 (props: equipmentId, sensorType) |
| ThresholdLines | 차트 임계치 기준선 오버레이 |
| ShiftIndicator | 현재 교대 D/N 표시 |
| ConfirmDialog | 상태 전환·확정 등 파괴적 액션 공통 확인 |
| EmptyState | 데이터 없음 (일러스트 없이 텍스트+아이콘, 담백하게) |
