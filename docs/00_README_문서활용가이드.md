## 1. 이 프로젝트가 뭔가

취업용 포트폴리오 프로젝트. 흔한 게시판/쇼핑몰 대신, **3년 현장 경험이 녹아 있어 아무도 못 따라 하는** 설비관리 시스템을 만든다.

- 기술 스택: Spring Boot 3.x (Java 17) + React 18 (TypeScript) + MySQL
- 기간: 1개월 집중 (로드맵은 07 문서)
- 수익화: 취업 우선, 설계만 구체적으로 반영 (08 문서)

## 3. AI 협업 원칙 (토큰 절약 + 품질 유지)

1. **새 대화를 열면 memory.md부터 읽힌다.** 현재 상태·다음 할 일이 다 거기 있다.
2. 전체 문서를 매번 넣지 않는다. 작업 단위에 필요한 문서 섹션만 투입.
   - 기능 하나 개발 → 03의 해당 기능 섹션 + 05의 관련 테이블 + 06의 관련 API만
   - UI 작업 → 04의 공통 토큰 + 해당 화면 섹션만
3. 한 대화 = 한 기능. 대화가 길어지면 새 대화 + memory.md + 필요한 명세 섹션 재투입.
4. **작업이 끝날 때마다 memory.md를 갱신한다.** (완료 항목, 결정 사항, 다음 할 일)

### 권장 프롬프트 템플릿
```
memory.md를 읽고 이어서 작업해줘.
이번 작업: [예: 점검 이력 등록 API 구현]
- 스택: Spring Boot 3.x + JPA + MySQL, 코드에 한국어 주석
- 명세서의 비즈니스 규칙과 예외 케이스 전부 처리
- 완료 후 memory.md 갱신

[03 문서의 해당 기능 섹션]
[05 문서의 관련 테이블 섹션]
```
